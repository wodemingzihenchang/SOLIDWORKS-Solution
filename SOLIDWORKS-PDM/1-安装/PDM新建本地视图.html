方法2：PDM管理创建

连接服务器库

首次安装 SOLIDWORKS PDM 客户端后，必须在 PDM 管理中识别存档服务器。(如果已经连接服务器，这一步可以跳过)

连接PDM库

打开【“开始菜单”>“SOLIDWORKS PDM”>“管理”】程序。找到PDM数据库，右键连接。

连接时，会要求你进行登录，输入你的【用户名称】和【密码】即可。

生成当地视图

连接登录后，再【右键-生成当地视图】，并在提示共享库视图，选择”是“：以便该计算机上的其它用户访问

创建快捷方式

打开Windows资源管理器,将PDM库的本地视图拖至桌面创建其快捷方式，或者拖放到快速访问进行固定，方便以后使用PDM

问题

bad data

当我尝试登录到 SOLIDWORKS® Enterprise PDM 库视图或通过管理工具进行访问时，什么原因会导致“cryptographic failure（加密失败）”或“bad data（不良数据）”错误？

客户端日志将显示以下错误：
-–
Description: Cryptographic failure.(Windows® Sockets error #-2146893819)
模块：ConisioAdmin.exe
Function: CFVLogin::SimpleConnectEx<-LoginConnection::mvRecvLoginStruct<-LoginConnection::mvRecvEncrypted<-CryptSocket::mvRead
Error code: 0x80090005
Error code general description: Bad Data.
-–

解决方案是客户端降级或服务器升级。然后客户端和服务器都是相同的版本和 Service Pack。

如果您刚刚将客户端升级到正确的版本，则当您看到此问题时，您可能必须首先重新启动工作站，然后登录才能正常运行，因为内存中可能仍然加载了一些较旧版本的 DLL。

从 2016 版开始，允许次要 Service Pack 版本不匹配，但主要版本（2016、2017 等）必须匹配。
